# PharmacyConnect - PC Software

This is the React + Vite + TypeScript application for Pharmacy Owners.

## Technology Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **Icons**: Lucide React

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Structure
- `src/layouts`: Contains the `DashboardLayout` component with the sidebar and top header.
- `src/pages`: Contains all route components (Dashboard, Login, Orders, etc.).
- `src/components`: For reusable UI components (buttons, inputs, cards).
- `src/services`: For future API calls to the Backend.
- `src/utils`: Helper functions.

*Note: This project is part of the PharmacyConnect ecosystem and relies on the central backend for actual data.*
